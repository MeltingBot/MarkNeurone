# Réglages

La roue dentée de la carte MarkNeurone, dans la section « Extensions » de la page d'accueil de ZeroNeurone, ouvre les réglages. Ils valent pour tous les dossiers. « Valeurs par défaut » rétablit les réglages d'origine, « Enregistrer » les applique.

## Onglet « Tags »

- **Tags proposés** à la création d'un élément, choisis parmi ceux du gestionnaire de tags de ZeroNeurone, neuf au plus. Leur ordre donne les raccourcis Alt+1 à Alt+9. Leur couleur est celle du tag dans ZeroNeurone.
- **Propriétés de surnom** : la valeur de ces propriétés est cherchée dans les documents comme un autre nom de l'élément. Par défaut « Alias ». Par exemple, une propriété « Alias » valant « Le Grand » sur l'élément Jules TERRIER fait signaler « Le Grand » dans les documents.
- **Tag et propriété par type de suggestion** : le tag ou le nom de propriété proposé lorsqu'une suggestion est traitée (téléphone, plaque, IBAN...). Lorsqu'une nouvelle version ajoute un type, il reçoit ses valeurs par défaut, sans modifier vos choix pour les types existants.
- **Nom des nouveaux éléments en majuscules.**

## Onglet « Reconnaissance »

- **Identifiants reconnus** : la France est toujours active. Cochez la Belgique, la Suisse ou le Luxembourg pour rechercher aussi leurs identifiants dans les suggestions (numéros nationaux, numéros d'entreprise, téléphones, plaques, francs suisses). Ces pays sont désactivés par défaut. Le tableau des tags et propriétés par type de suggestion ne montre que les types des pays cochés.
- **Retirer l'encre de couleur (tampons) avant la reconnaissance.** Activé par défaut. À désactiver si les documents comportent du texte utile imprimé en couleur. Le changement s'applique aux pages reconnues ensuite. Pour l'appliquer à un document déjà traité, effacez son texte reconnu depuis le lecteur.

## Onglet « Liens »

- **Mode verbe** : surligner les mots d'une relation propose comme extrémités les éléments surlignés les plus proches dans la phrase. Désactivé par défaut. Voir [Créer des liens](liens.md).
- **Liens possibles signalés dans la marge** : désactivé, même phrase ou même paragraphe. Désactivé par défaut.

## Onglet « Formulaires »

Les modèles de formulaire importés, avec leurs rubriques. « Importer un modèle » ajoute un fichier JSON ; un modèle de même identifiant remplace le précédent. Chaque modèle peut être exporté ou supprimé. « Valeurs par défaut » ne supprime pas les modèles. Voir [Formulaires](formulaires.md).
