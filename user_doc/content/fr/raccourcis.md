# Raccourcis clavier

| Touche | Action |
|---|---|
| E | Créer un élément à partir de la sélection |
| P | Ajouter une propriété à partir de la sélection |
| V | Ajouter un événement à partir de la sélection |
| G | Renseigner une localisation à partir de la sélection |
| Alt+1 à Alt+9 | Ajouter un tag proposé, dans le formulaire de création d'élément |
| Entrée | Valider le formulaire |
| Ctrl+clic | Sélectionner plusieurs passages surlignés |
| L | Créer un lien entre les deux passages sélectionnés ; avec le mode verbe, créer un lien à partir des mots sélectionnés |
| Z | Encadrer un passage à la souris |
| I | Encadrer une image à la souris, pour en faire la source d'un élément |
| M | Masquer ou afficher le texte du document |
| Suppr | Ignorer la suggestion sélectionnée |
| Ctrl+F | Rechercher dans le document |
| Entrée, Maj+Entrée | Résultat de recherche suivant, précédent |
| Clic du milieu et glisser | Déplacer le document |
| Ctrl+molette | Agrandir ou réduire le document autour du pointeur (pincement sur un pavé tactile) |
| Échap | Fermer la liste ou le formulaire ouvert, vider la sélection, puis réduire le lecteur |

Les raccourcis du canvas de ZeroNeurone (Suppr, Ctrl+Z...) sont désactivés tant que le lecteur est ouvert, pour éviter de modifier le graphe par erreur.
